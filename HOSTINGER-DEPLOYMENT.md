# Hostinger Node.js upload

Upload Aariva-Hostinger-Nextjs.zip on the Upload your app files screen.
package.json, app/ and next.config.mjs are at the archive root.

Framework: Next.js
Node.js: 22 or newer supported version
Root directory: ./
Install command: npm ci
Build command: npm run build
Start command: npm start
Build output: .next (if requested)

Hostinger installs dependencies and builds the app. node_modules, .next and out are deliberately excluded.
This package runs Next.js in server mode. The separate Ready-to-Host ZIP is a static export for File Manager / public_html, not this framework upload screen.

Includes the latest hotel exterior showcase. No secrets or environment variables are required for WhatsApp enquiries.
